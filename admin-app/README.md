# youridea.in Admin Dashboard

## Quick start

```bash
cd admin-app
npm install
npm start
```

Then open:

- http://localhost:3000

## Demo login

- Username: `admin`
- Password: `admin123`

## Features

- Premium admin dashboard UI
- Login authentication with JWT
- Project management
- Enquiry tracking
- Service and pricing overview
- Mobile responsive layout

## Notes

This is a working starter full-stack admin dashboard built with:

- Node.js
- Express
- JWT authentication
- JSON file storage

It keeps the existing GitHub Pages site untouched while adding an advanced admin backend and dashboard.
